# Definition of Done — executive-coach

A code task is done when the tests pass. A practice task is done when the record
is honest. These lines are written to be answerable from the log, not from memory.

- [ ] The change is recorded in `log.md` with a real date — not "recently".
- [ ] If this changed the **protocol**, `protocol.md` says what changed and why the
      old version stopped working. A protocol edited silently is a protocol nobody
      is accountable to.
- [ ] If this claims progress, a number in `measurements.md` supports it. An
      unmeasured claim of progress is recorded as a feeling, and labelled as one.
- [ ] Adherence is stated honestly, including the misses. A log with no misses is
      evidence of a log that is not being kept, not of a protocol being followed.
- [ ] No past entry was rewritten. Corrections are appended with today's date and
      a note, never edited in place.
- [ ] `just verify-safe` is green — schema conformance, link integrity, and date
      coherence (PH8-T03).
